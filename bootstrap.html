Info om ramverket

Bootstrap är det populäraste CSS-ramverket. Dess fokus ligger på att att skapa responsiva, mobile-first webbappar med hjälp av HTML, CSS och JavaScript. Det används oftast som ett komplement till webappar för att lägga till ramverkets utbud av färger, typsnitt och layouts. Bootstrap erbjuder också styling för text, tabeller och formulär. Utseendet på dessa är uniformt och ger en "Bootstrapp-look". De JavaScript-komponenter som Bootstrap erbjuder interface-element såsom dialogrutor och "drop down"-menyer.

Det är gratis att använda.
